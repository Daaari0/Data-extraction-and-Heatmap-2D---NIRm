# Data-extraction-and-Heatmap-2D---NIRm
It extracts, analyzes, and plots spatial data acquired from oscilloscope Promax OD-606. The script reads raw data from multiple .xls files, calculates descriptive statistics, normalizes acquisition time deltas, maps data onto an ordered 2D spatial coordinate system, and generates both linear-scale and Log10-scale signal intensity heatmaps.
